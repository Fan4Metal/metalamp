# Keys

<!-- Moved from CLAUDE.md, which points here. -->

The defaults of `keymap.rs` (changed on the settings' Keyboard shortcuts page; `App::run_key`):

Space or C: play/pause; X: play; V: stop; Shift+V: stop after the current track; Ctrl+Right or B: next; Ctrl+Left or Z: previous (Z X C V B); Shift+Left/Right, or Left/Right with the pointer over the title row or the player bar (`App::player_area`, the frame before's): back/forward by `seek_step` (the General page's Playback card, 1–60 s, 5 by default; `Cmd::Seek(±1)` is the way, `Settings::seek_seconds` the step); Ctrl+Up/Down, or Up/Down with the pointer over the title row or the player bar: volume by `volume_step` (the Playback card, 1–25 %, 5 by default; `Cmd::Volume(±1)`, `Settings::volume_percent`, `App::step_volume`, also the wheel's); M: mute; R: repeat; S: shuffle; Ctrl+F: search; Ctrl+1…9: the whole library (1) or a view, in the order of the views' menu; Ctrl+M (or Esc in it): the mini player; Ctrl+T: over the other windows; Alt+L: the window layout (with the library / player and playlist; also the title row's menu); Ctrl+O: open files (they replace the playlist; M3U/M3U8 are opened as their entries); Ctrl+Shift+O: add a folder; Alt+E: the playlist; I or Alt+3: the file info window (a click on the player bar's cover too); Shift+I: the track's spectrum (`Cmd::Spectrum`: the file `App::info_path` takes, its heading and facts from the library's or the outside track, `track_spectrum::about`; in the file info, the file shown, `InfoView::keys`); Ctrl+E: the file info editing the tags (the playlist's selection when it has the keys or in the player and playlist layout, else `LibraryView::tracks_to_edit` by the pane last clicked: the tracks' table's selection, or the tracks of the album or artist chosen (an album clicked with no track selected gave nothing and the key seemed dead); "All" alone none; in the window, its Edit); G / Shift+G: go to the track's album / artist (`Cmd::GoTo`, `App::go_to_track`: the playlist's selection when it has the keys, the tracks' table's when that pane has them, else the track heard; nothing in the player and playlist layout; leaves the mini player); Delete: remove from the playlist; Ctrl+R: the file in Explorer (`Cmd::ShowInFolder`, the file `App::info_path` takes; the menus' "Show in folder" name it; reading the folders again has no key by default, the user's choice); F1: About; F5 or Ctrl+P: the settings window; F6: the library's statistics; the arrows, Page Up/Down, Home/End move in the pane last clicked, Enter plays; letters with the pointer over the artists go to an artist (the letter keys above wait then). Media keys (keyboards, headsets) come through the window's subclass, and while another window is active through Windows' media controls (`media_keys`: `always`/`window`/`off`, the General page); the taskbar button's thumbnail has Previous, Play/Pause and Next. The player's keys (Space, the letters, the arrows, Enter, Delete, I) wait while a text field has the focus; F1, F5, Ctrl+P, Ctrl+O, Ctrl+Shift+O, Ctrl+R, Ctrl+F, Alt+E and Alt+3 work then too. Outside the modals only a text field keeps the focus (`App::ui` drops a button's, which Tab gave). Files and folders dropped on the window go to the playlist's end (`App::take_dropped` walks each drop on a "dropped" thread, `files_of_dropped`, which wakes the app; `follow_dropped` in `logic` enqueues the walks in the order of the drops; played if stopped): a folder as its audio files and its subfolders' (`audio_in_folder`: in each folder the subfolders, then the files, by `natural_cmp`, as Explorer; its playlists left out, tested), a playlist as its audio entries (`expand_playlists`); the library takes folders only from its menu (`Ctrl+Shift+O`, Add a folder…), the user's choice.
